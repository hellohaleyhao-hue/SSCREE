# SSCREE

Steric Strain Calculation and Repulsive Energy Estimation (SSCREE)

## Introduction

Estimating the impact of specific missense gene mutations on protein structure, thus function, comes from various sources of evidence such as changes to bonding, positional shifts, and evolutionary conservation. Steric clashes occur when the atoms of the mutated amino acid are in close proximity to surrounding atoms.

Generally, the more clashes there are, the less stable the variant will make of the protein. Since natural selection optimizes native protein chains to pack tightly without severe destabilizing overlaps in the electron cloud, this tool, which calculates the total steric overlap from all atoms in the sidechain and surrounding atoms as a strain value, can be used to predict the pathogenicity of that variant, especially variants of uncertain significance (VUS).

SSCREE is a PyMOL-integrated Python tool for evaluating local steric overlap caused by amino acid substitutions. It enumerates mutant side-chain rotamers via PyMOL's Mutagenesis Wizard, calculates geometric steric-strain scores based on Van der Waals overlaps, categorizes strain by surrounding atom types, and offers batch visualization tools (beeswarm plots).

> **Scientific Scope:** SSCREE measures geometric steric overlap ($\text{Å}^2$). It is a structural evidence feature, not a calibrated physical energy calculation or clinical pathogenicity classifier.

## Features

- **Rotamer Enumeration:** Automatically evaluates all rotamers generated by PyMOL's Mutagenesis Wizard.
- **Categorized Overlap:** Deconstructs steric strain into `protein`, `nucleic`, `organic`, `inorganic`, `solvent`, and `other`.
- **Batch Processing & Plotting:** Processes variant lists and outputs high-resolution, frequency-weighted beeswarm plots.
- **Flexible Integration:** Supports both PyMOL command-line interface (CLI) and Python API.

## Usage & Commands

### 1. PyMOL CLI

Load the script inside PyMOL and run commands:

```pymol
run lib/sscree.py
config data/TTR_alphafold_homotetramer.pdb
set_h off
calculate_strain Val30Met, chain A
```

#### Command Reference

| Command | Usage | Description |
|---|---|---|
| `config` | `config <path_to_structure>` | Load target structure (`.pdb`, `.mmcif`, `.pse`). Required. |
| `calculate_strain` | `calculate_strain <WT><Resi><Mut>, [chain]` | Calculate strain for a mutation (default chain: `chain A`). |
| `set_h` | `set_h on` / `set_h off` | Toggle hydrogen inclusion in strain calculation (default: `off`). |
| `help` | `help` | Display command help in PyMOL console. |

### 2. Python API

```python
import lib.sscree as sc

# Configure structure
sc.model.config("data/TTR_alphafold_homotetramer.pdb")

# Calculate variant
results = sc.model.calculate_strain_value("Val30Met", chain="chain A")
```

### 3. Batch Analysis & Plotting

Format input variants in a text file (e.g., `data/variant_list.txt`):
```text
Thr5Ile     A
Gly6Ser     A
Val30Met    A
```

Execute batch plotting via `run_plotter.py` or Python:

```python
import lib.strain_plotter as sp

sp.run_pipeline(
    variant_file_path="data/variant_list.txt",
    structure_path="data/TTR_alphafold_homotetramer.pdb",
    output_path="outputs/beeswarm_plot.png",
    strain_category="protein",  # Options: total, protein, nucleic, organic, inorganic, solvent, other
    default_chain="chain A"
)
```

## Steric Strain Calculation

For each mutant side-chain atom $i$ and surrounding atom $j$ within the search distance:

$$\text{Overlap}_{ij} = \max(0, \text{vdw}_i + \text{vdw}_j - d_{ij} - \text{buffer})$$

$$\text{Total Strain} = \sum (\text{Overlap}_{ij})^2 \quad (\text{Unit: }\text{Å}^2)$$

### Default Parameters

| Parameter | Default | Description |
|---|---:|---|
| `include_hydrogen_atoms` | `False` | Excludes hydrogen atoms from calculations. |
| `search_distance` | `5.0 Å` | Maximum interaction radius around side-chain atoms. |
| `buffer` | `0.4 Å` | Distance tolerance subtracted from Van der Waals radius sums. |

---

## Output Data Format

`calculate_strain_value()` returns a list of rotamer records:

```python
[
    rotamer_index,       # int: PyMOL rotamer ID
    frequency,           # str: Rotamer probability (e.g., "16.2%" or "N/A")
    total_strain,        # float: Total strain (Å²)
    protein_strain,      # float: Strain from protein atoms
    nucleic_strain,      # float: Strain from nucleic acids
    organic_strain,      # float: Strain from organic ligands/cofactors
    inorganic_strain,    # float: Strain from ions/metals
    solvent_strain,      # float: Strain from water/solvent
    other_strain         # float: Strain from remaining objects
]
```

## Troubleshooting

- **`ModuleNotFoundError: No module named 'lib'`**: Ensure you run scripts from the **repository root**.
- **`No PDB file pathway configured`**: Call `config <path>` before running `calculate_strain`.
- **`Sequence mismatch`**: Ensure the wild-type residue matches the sequence and numbering scheme of the structure.
- **`Ambiguous selection`**: Ensure the structure does not contain duplicate alternate states/models for the target residue.
- **Plotting Failure**: Verify Matplotlib/pandas/seaborn are installed in PyMOL's Python environment and ensure `outputs/` exists.
